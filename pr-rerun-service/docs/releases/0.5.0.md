# PR rerun 0.5.0

Add opt-in repository CI analytics using the existing GitHub App and service login.

- `pr-rerun stats`: first-attempt job failure counts/rates, failed steps, rerun
  recovery, duration percentiles, filters and JSON output.
- `pr-rerun-admin ci-sync`: read-only Actions collection into a separate SQLite
  database, with bounded requests, time-window splitting, checkpoints and a lock.
- Per-repository analytics enablement and administrator/repository-user visibility.
- systemd collector/timer templates; explicit incomplete/stale report indicators.

Upgrade both server and client. Existing login sessions remain valid. Statistics
are disabled until a maintainer opts in and an operator collects data. No additional
App permissions or webhook is required. Back up the service database: policies
saved with new analytics fields cannot be read by older strict policy validators.
See [the statistics guide](../ci-statistics.md) before deploying.
