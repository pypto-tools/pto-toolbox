# PR rerun 0.6.0

Collect bounded, redacted CI error excerpts in an independent background task.
Use `pr-rerun errors --repo pypto --days 30`, add `--group` for similar-summary
counts, and `pr-rerun error <ID> --repo pypto` for context and the GitHub job link.

Error excerpts have a separate per-repository opt-in and default to maintainer
access. Public aggregate statistics do not grant access to logs. No reruns are
triggered. Raw logs and signed URLs are not stored; service API credentials are
never sent to log storage.
Redaction and classification are best-effort, so excerpts remain restricted data.

Upgrade the server and client, enable `error_logs_enabled`, and configure the
independent `error-sync` timer. Both collectors reserve 1,000 GitHub API requests.
Existing logins remain valid. Back up databases before enabling new policy fields;
older servers cannot read those fields without migration or restoring a backup.

See [setup and limitations](https://github.com/pypto-tools/pto-toolbox/blob/main/pr-rerun-service/docs/ci-errors.md).
