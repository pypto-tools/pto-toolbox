# PR rerun 0.6.0

新增独立后台任务，采集有大小限制且经过脱敏的 CI 错误片段。
用 `pr-rerun errors --repo pypto --days 30` 查看列表，加 `--group` 聚合相似摘要；
用 `pr-rerun error <ID> --repo pypto` 查看上下文与 GitHub job 链接。

错误片段按仓库独立开启，默认仅维护者可读；开放汇总统计不会自动开放日志。
不会触发重跑，不保存完整日志或签名下载地址。脱敏和分类均为尽力处理，片段仍需限制访问。

需同时升级服务端与客户端，启用 `error_logs_enabled` 并配置独立的 `error-sync` 定时任务。
两个采集器均预留 1,000 次 GitHub API 额度。已有登录保留；启用新规则前备份数据库，
旧服务端降级需要迁移规则或恢复备份。

参见[配置与限制](../ci-errors.zh-CN.md)。
