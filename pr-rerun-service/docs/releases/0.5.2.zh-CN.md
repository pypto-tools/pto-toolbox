# PR rerun 0.5.2

CI 统计改用 Rich 边框表格，数值右对齐，长 job 名称自动换行。窄终端按 job
分别展示指标表格。workflow、job 和步骤名称（包括方括号）均按原文显示。
重定向输出不会自动添加颜色；可用 `NO_COLOR=1` 关闭终端颜色。

失败率列：当前展示的最高非零值标红（包括并列），其它非零值标黄，零值标绿，
无有效样本显示灰色 `-`。

两种架构的独立 Linux 客户端均包含 Rich、依赖及许可文件，无需在客户端机器上
额外安装 Python 包。

只需更新客户端；兼容服务端 0.5.0，已有登录、统计口径和 JSON 格式不变。
共享客户端更新命令：`sudo pr-rerun-update --version 0.5.2`。
