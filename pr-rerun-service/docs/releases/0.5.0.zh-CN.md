# PR rerun 0.5.0

新增按仓库启用的 CI 统计，复用 GitHub App 和现有服务登录。

- `pr-rerun stats`：首次 job 失败次数/失败率、失败 step、重跑恢复、耗时分位数、筛选及 JSON。
- `pr-rerun-admin ci-sync`：只读采集到独立 SQLite，限制请求量，拆分时间窗口，支持断点进度和进程锁。
- 每仓库单独开启统计，可限制为管理员查看或向仓库有权用户开放。
- 提供 systemd 采集器和定时器模板，报表明确标注不完整及陈旧数据。

客户端和服务端都要升级，现有有效登录保留。默认关闭统计，需管理员启用并完成采集。
无需新增 App 权限或 Webhook。升级前备份服务数据库：保存新统计字段的规则不能被旧版
严格校验器读取。部署前阅读 [CI 统计指南](../ci-statistics.zh-CN.md)。
