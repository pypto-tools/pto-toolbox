# PR rerun 0.4.0

Linux 客户端无需构建 wheel 或升级系统 Python 即可安装更新。提供原生 ARM64、x86_64
安装包，内含运行环境，要求 glibc 2.28 以上；首次安装器支持系统 Python 3.9 以上。

- 独立客户端不包含服务端、管理模块及服务端依赖。
- 全机共享安装提供 `pr-rerun`、`pr-rerun --version` 和 `pr-rerun-update`。
- 支持 HTTP 代理、离线包、SHA-256 校验、切换前自检及回退到上一个独立版本。
- 保留各用户登录信息和个人别名；旧共享安装通过 `--migrate-existing` 显式迁移。
- 单独提供服务 wheel；更新客户端不会升级或重启正在运行的服务。

详见[安装指南](../client-releases.zh-CN.md)。发布包只包含公开代码和依赖，
不包含服务私钥、数据库、用户登录状态或部署凭据。
