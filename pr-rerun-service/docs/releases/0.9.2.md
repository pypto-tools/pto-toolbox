# PR rerun 0.9.2

Fix discovery of PyPTO Full CI runs whose titles now end with
` request:RUN_ID-ATTEMPT`. Older servers require the title to end at the base SHA
and silently omit these runs, even when the current PR's Full CI has failed.

Accept the optional suffix only with positive decimal run and attempt IDs.
Preserve legacy titles, latest-request selection, trusted workflow/repository
checks, current PR head/base/merge verification and rerun-time revalidation.
Tests exercise both title formats through preview and submission and reject
malformed suffixes. Live validation is read-only; it does not trigger CI.

Upgrade the backend package and restart the API. No repository policy change,
client upgrade or new login is required. Client 0.9.1's confirmation improvements
remain included. See the [Full CI guide](../multi-repository.md#pypto-comment-triggered-full-ci-server-081).
