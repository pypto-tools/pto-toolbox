# PR rerun 0.7.0

AI tools can now query CI data through `pr-rerun mcp`, a local stdio MCP adapter
included in the ARM64 and x86_64 standalone clients and the Python package.

- Four read-only tools: list repositories, query first-attempt CI statistics,
  list all-attempt errors and similar-error groups, and retrieve error excerpts.
- Reuses the current OS user's saved login, repository default and local/official
  aliases; no App key, new listener, service registration or additional login.
- Keeps coverage, stale status and truncation visible to AI. Existing repository
  statistics/error-log permissions continue to apply.
- Fixed GET endpoints only; rejects redirects, arbitrary URL/method arguments
  and unknown tools. Does not expose rerun, sync or policy changes.
- No new runtime dependencies or backend modules in the standalone client.

Update clients with `sudo pr-rerun-update --version 0.7.0`, then configure the AI
host to launch `/usr/local/bin/pr-rerun mcp --repo pypto` via stdio. Saved logins
remain valid. Existing 0.6.0 servers do not need upgrading or restarting.
See [setup and boundaries](../mcp.md) / [中文配置说明](../mcp.zh-CN.md).

The adapter exposes a read-only tool surface; the reused session is not a
server-enforced read-only credential. Other AI tools retain their own permissions.
