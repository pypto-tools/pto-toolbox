# PR rerun 0.9.2

修复 PyPTO Full CI 标题新增 ` request:RUN_ID-ATTEMPT` 后无法被发现的问题。
旧服务端要求标题结束于 base SHA，因此当前 PR 的 Full CI 即使失败，也可能被遗漏。

只接受两部分均为正十进制整数的可选后缀，并兼容旧标题。
最新请求选择、可信仓库和 workflow、当前 PR head/base/merge 校验及提交前复核继续生效。
测试覆盖两种标题的预览、提交和无效后缀拒绝；真实仓库验证只读，不触发 CI。

升级后端包并重启 API 即可，无需修改仓库规则、升级客户端或重新登录。
此版本保留客户端 0.9.1 的确认输入改进。
参见 [Full CI 指南](../multi-repository.zh-CN.md#pypto-评论触发的-full-ci服务端-081)。
