# PR rerun 0.9.1

确认时无法识别的输入会提示有效选项，并重新询问同一个 PR，不再直接显示取消。
只有 `y` 确认；`n` 或空输入取消，大小写和首尾空白仍会忽略。
不会回显无效内容，也不会将其自动转换为授权。

原有预览票据、服务端过期校验和逐 PR 确认规则保持不变。
测试覆盖输入纠正、取消、中断，以及两种架构客户端真实 TTY 的输入输出。

在每台受影响的服务器更新共享客户端：

```bash
sudo pr-rerun-update --version 0.9.1
pr-rerun --version
```

已有登录保留，服务端无需升级。此版本改善取消提示和纠错流程；正常输入 `y` 却取消的具体原因，
仍需出问题机器的版本和终端证据确认，不能直接归因于用户输入。
参见[排障说明](../operations.zh-CN.md#确认输入与意外取消客户端-091)。
