# PR rerun 0.5.2

Display CI statistics with Rich bordered tables, right-aligned numeric columns and
wrapped job names. Narrow terminals show a metric/value table per job. Workflow,
job and step names are rendered literally, including brackets. Redirected output
has no automatic colors; `NO_COLOR=1` disables terminal colors.

Rates use red for the highest nonzero value shown (including ties), yellow for
other nonzero values, green for zero, and dim `-` for no terminal samples.

Rich and its dependencies are bundled in both standalone Linux clients, with
license notices. No extra Python packages need to be installed on client hosts.

Client-only update; server 0.5.0, existing logins, metrics and JSON remain compatible.
Update shared clients with `sudo pr-rerun-update --version 0.5.2`.
