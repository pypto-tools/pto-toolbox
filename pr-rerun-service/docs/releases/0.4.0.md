# PR rerun 0.4.0

Linux clients can now be installed and updated without building wheels or upgrading
the system Python. Native ARM64 and x86_64 archives bundle the client runtime and
require glibc 2.28+. The initial installer supports system Python 3.9+.

- Client-only archives exclude server/admin modules and server dependencies.
- Shared installs provide `pr-rerun`, `pr-rerun --version` and `pr-rerun-update`.
- Updates support HTTP proxies, offline archives, SHA-256 verification, pre-switch
  self-tests and rollback to the previous installed standalone version.
- Existing per-user logins/aliases remain unchanged. Legacy shared installations
  can migrate explicitly with `--migrate-existing`.
- The separate service wheel remains available; client updates do not restart or
  update the running service.

See the [installation guide](../client-releases.md) and
[中文安装指南](../client-releases.zh-CN.md). On the GitHub Release page, use the
[repository guide](https://github.com/pypto-tools/pto-toolbox/blob/pr-rerun-v0.4.0/pr-rerun-service/docs/client-releases.md).

The packages contain public code and runtime dependencies only. No service private
keys, database, user login state, or deployment credentials are included.
