# PR rerun 0.9.0

在明确开启 `comment_reruns_enabled` 的仓库，PR 作者可新发 `/ci rerun` 评论请求重跑。

- 校验 GitHub 签名、作者数字身份、仓库安装和原始评论，复用已有 workflow、PR 和使用规则。
- 先持久化再应答，防止重复投递和重复评论执行；过期命令及结果不确定的请求不会自动重放。
- GitHub 写操作仍仅限重跑，不回复评论、不创建首次运行、不批准 workflow。
- 新增 `pr-rerun-admin comment-commands --repo owner/repo` 查询本地审计记录。
- 提供仅转发 Webhook 的 Nginx 示例和中英文部署说明。

先升级 API、管理员命令及两个采集器，再写入新规则。客户端无需更新，已有登录继续有效。
配置私密 Secret、HTTPS 转发、App 的 Issues read 权限和 Issue comment 订阅后逐仓开启。
未配置 Secret 时端点关闭，仓库默认不启用。参见[部署指南](../comment-commands.zh-CN.md)。
