# PR rerun 0.4.1

- 新增 `pr-rerun repos [--json]`，列出服务仓库、别名、启用状态、角色和规则版本。
  服务管理员查看全部登记；其他用户按权限过滤，仓库管理员还能看到自己管理的停用项。
- 新增服务端命令 `pr-rerun-admin installations [--json]`，实时对比 App 授权与服务登记。
  支持分页，明确标记暂停、授权缺失、身份变化和部分失败；只申请元数据只读凭据，
  不输出凭据，不修改服务登记、仓库规则或工作流。
- `repos` 需要 App 模式服务端和客户端都升级到 0.4.1；连接旧服务会明确提示升级。
  原重跑行为和用户登录不变。管理员查询命令只随服务端包提供。

详见[查询说明](../../README.zh-CN.md)及[安装更新指南](../client-releases.zh-CN.md)。
