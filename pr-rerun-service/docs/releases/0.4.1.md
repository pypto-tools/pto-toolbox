# PR rerun 0.4.1

- `pr-rerun repos [--json]` lists service repositories, aliases, enabled state,
  role and policy revision. Service admins see all enrollments; other users see
  only authorized repositories, and maintainers can also see their disabled ones.
- `pr-rerun-admin installations [--json]` compares live GitHub App authorization
  against the existing service database without modifying enrollment or rules.
  Pagination, suspended installations, missing authorization, changed identities
  and partial failures are reported explicitly. Only metadata-read tokens are
  requested, and credentials never appear in the report.
- Upgrade both the App-mode server and clients to use `repos`. Older servers
  produce an explicit upgrade message. Existing rerun behavior and user logins
  are unchanged. The admin command belongs to the service package only.

See the [query documentation](https://github.com/pypto-tools/pto-toolbox/blob/pr-rerun-v0.4.1/pr-rerun-service/README.md#repository-inventory-041)
